{\LARGE\bfseries Deasy's requests R1--R3: every exhibit, one page each}\par\vspace{10pt}
{\large Project 1014 (Deasy--Imed paper): firm panel of Indonesian manufacturing, 2010--2022}\par\vspace{24pt}
\begin{minipage}{0.85\linewidth}\small
Each page shows one chart or table built from \texttt{analysis\_ready\_data.dta} with one standalone Stata do-file, and says
in plain words what it is, how to read it, what it shows on this file, and which part of Deasy's request it answers.
Every number was re-computed independently by a reviewer before the exhibit was accepted.\par\medskip
\textbf{This is development data}: values are obscured and the firm links are fictional (a firm's later records may belong to
another real firm). The pages test the method and the wording. They are not findings about Indonesian firms; the same
do-files run on the real BPS files.\par\medskip
Where to find things: \texttt{20260917-run/block-r1-paris-internationalisation/}, \texttt{block-r2-internationalisation-energy-efficiency/},
\texttt{block-r3-energy-emissions-correlates/}. Each block has \texttt{00\_run.do} (runs everything), one do-file per exhibit,
\texttt{INDEX.md} (details kept out of the figures) and \texttt{TRACKER.md} (every item of Deasy's row and its status).
\end{minipage}
