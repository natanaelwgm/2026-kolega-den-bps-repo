Wave tahunan hanya dibaca oleh penggabung. Kalau variabel yang dibutuhkan belum ada, perbaiki penyiapan data sebelum dataset gabungan disahkan. Setiap do-file dan bloknya harus diberi komentar kode yang menjelaskan tujuan, masukan dan hasil dalam bahasa sederhana. Rencana semula dipertahankan di bawah sebagai konteks; pengikatan input di bagian revisi ini dan JSON revisi menggantikan pengikatan ke kandidat perusahaan lama.

## Decisions before execution

### G21b_DEC_SOURCE — Which input release is analyzed?

Freeze G0 release hash and exact field binding, together with G2 QA and any required G1 model release. No guessed raw variable names.

Why: The call requires one stable schema and a version bridge.
Sensitivity: Old/current values only in a separately labeled reconciliation branch.
Reopen only if: Upstream release, unit, definition or codebook evidence changes.

### G21b_DEC_YEARS — Which calendar years are in the plan?

Register every 2010–22 calendar year. Unobserved 2016 remains an explicit unavailable cell; no interpolation or carrying observations across years.

Why: Time gaps must be visible in trends and changes.
Sensitivity: Adjacent observed-wave changes retain actual year distance.
Reopen only if: A verified missing-year source is supplied.

### G21b_DEC_BASIS — What do the numbers represent?

Primary empirical cross-sections use measured rows with provenance keys. Panel-derived quantities require verified real plant IDs. Artificial-ID and fully synthetic branches are distinct demonstrations.

Why: Measured values do not make manufactured links factual.
Sensitivity: These are separate data modes, never pooled as robustness evidence.
Reopen only if: Verified real-ID crosswalk or source release arrives.

### G21b_DEC_GROUP — How is the comparison group defined?

Country dictionary must be exhaustive and exclusive. Fix 2014 EU and ASEAN membership for time comparison; time-varying membership is separate sensitivity. Known top-three reports stay top-three reports.

Why: The group definition changes denominators and interpretation.
Sensitivity: Explicit threshold/classification variants where relevant; never mutate main definitions.
Reopen only if: New annual questionnaire evidence invalidates the frozen classifier.

### G21b_DEC_WEIGHTS — Whose distribution is shown?

Primary observed-sample descriptions use equal weight per eligible source row. National totals or population-weighted claims are blocked without a documented representative design.

Why: The supplied sample is not automatically national.
Sensitivity: Separate weighted branch needs a frozen design and weighted-quantile rule before execution.
Reopen only if: A documented sampling-weight/design release becomes available.

### G21b_DEC_MISSING — How are unknown and unobserved values handled?

Missing≠zero. Keep structural absence, not asked, unknown, invalid and observed zero statuses. Primary verified-only results and working/provisional sensitivity use separate cell registries.

Why: Sparse R&D, energy and geography may reflect questionnaires rather than economic outcomes.
Sensitivity: Show sample differences as well as value differences.
Reopen only if: Field-year evidence clears or invalidates a value.

### G21b_DEC_DOMAIN — Which records support each outcome?

Ratios need their stated positive denominator; logs need positive value; zero/negative/missing exclusions are counted separately. No constant added to make logs exist.

Why: The denominator and log domain change the sample.
Sensitivity: Levels and logs are reported as distinct populations with counts.
Reopen only if: An outcome definition changes or invalid measurement is proved.

### G21b_DEC_PRICE — Which monetary units and price base apply?

Use concept-specific verified deflators and currency scale. Missing deflator yields missing real value; nominal values remain a separately named branch.

Why: A nominal increase cannot be called real growth.
Sensitivity: Never substitute deflator1 as fallback.
Reopen only if: Revised deflator, mapping or units evidence arrives.

### G21b_DEC_PERIOD — How are yearly and pooled statistics formed?

Each eligible record enters its observed-year cell and one pooled plant-year cell. Pooled values are not unique-plant statistics; no duplicated join rows.

Why: This makes pooling explicit and testable.
Sensitivity: Fixed-cohort panel views only when real-linkage gate passes.
Reopen only if: Question requires a distinct fixed-cohort target.

### G21b_DEC_STATISTICS — Which summaries are fixed before view ing results?

For every requested continuous field: n, mean, SD, min, max, P 10, P 25, P 50, P 75, P 90, P 95. For known categories:count and explicit denominator share. Use Stata documented default percentiles and save command/version.

Why: The entire family is fixed in advance, not selected for interesting patterns.
Sensitivity: No hypothesis tests or causal regressions are added to descriptive rows merely to fill output slots.
Reopen only if: A reviewer id en ti fi es a missing original-statistic requirement.

### G21b_DEC_OUTLIER — Can extreme values be removed?

Retain valid outliers in main results. Predeclared sensitivity excludes values below P1 or above P99 within outcome-year, with source and group classifications fixed.

Why: Silent cleaning can manufacture distribution changes.
Sensitivity: No win sori zed replacement of source values; show removed counts.
Reopen only if: A value is confirmed unit/coding error in upstream QA.

### G21b_DEC_THIN — How are sparse result cells displayed?

Always register cell and n. Mark n<10 thin; do not draw unstable detailed-sector distribution panels when n<10. Keep permitted numerical cell with thin flag; apply actual BPS disclosure rules if provided.

Why: Thin-cell clarity is separate from official disclosure policy.
Sensitivity: No invented BPS suppression threshold.
Reopen only if: An actual disclosure rule or statistical support requirement supersedes this display rule.

### G21b_DEC_COVERAGE — How are incomplete product, energy or factor data compared?

Use complete required-component universe for primary accounting; observed partial sums separate. Every numerator and denominator shares the same eligibility mask for the requested ratio.

Why: Reported small sums can reflect missing components.
Sensitivity: Vary component coverage and factor assumptions oneat a time.
Reopen only if: A verified source resolves the missing components or annual factor.

### G21b_DEC_ROW — What row-specific calculation is selected?

Build firm-destination-year values with exhaustive geographic group membership and documented time-varying EU/ASEAN conventions. Compute concentration/diversification with known denominators; define the high-environmental-standard classification independently of outcomes. Link feasibility to R5.

Why: Preserves the repository row-specific interpretation and records changes separately.
Sensitivity: Specialist branches below isolate mapping, threshold, tie, period and denominator choices.
Reopen only if: New evidence, current owner correction or independent method review requires revision.

### G21b_DEC_PUBLISH — Which results lead the row report?

First4 core exhibits where useful, then diagnostics and complete indexed appendix. Individually runnable row module saves outputs before other rows proceed.

Why: Deasy explicitly requests interpretable staged results, not one opaque grand run.
